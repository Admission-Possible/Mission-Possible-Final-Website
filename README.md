# (Ad)mission Possible

The (Ad)mission Possible website is a one-page, editorial-style experience for students exploring college, scholarships, and their next step. It includes application pathways, campus imagery, student-journey chapters, FAQs, and a Join Us form that prepares an email without storing submissions.

## Run locally

The project has no external dependencies. With Node.js installed:

```sh
npm run dev
```

Then open `http://127.0.0.1:4173/`.
